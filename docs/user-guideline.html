1. Getting started

  1. Open the app at https://scit.zya.me/trace (production) or run the PHP server locally so http://127.0.0.1:8099 responds (root index.php = OSINT Framework home). All links adapt to either base automatically.
  2. Open /sccrm/ for the CRM, /sccrm/ai/ for AI Chat, /ceo/ for the CEO Office.
  3. Everything degrades gracefully: if an integration (Ollama, ToolJet, WhatsApp) is offline you get a setup hint, never a crash.
Example: first visit → Dashboard shows KPI cards. If a card says “unconfigured”, follow its hint (e.g. set TOOLJET_HOST) — the rest keeps working.

2. Dashboard /sccrm/index.php

Live KPI cards (new leads, open tasks, tickets), module shortcuts, SLA badges. Click any card to jump to its module.

Example: “1160 new leads” card → click → filtered Leads list.

3. Leads /sccrm/leads/

List / create / edit / delete

  1. List: open leads/ — sortable table with score + status.
  2. Create: leads/create.php → fill Company “Acme Ltd”, Contact “Rahim”, Email, Source → Save.
  3. Edit/Delete: row actions → edit.php?id=… / delete with confirm.
  4. Logs: logs.php shows the audit trail of lead changes.

Lead generator + scoring

generate.php bulk-creates targeted leads; each lead carries a numeric score (higher = hotter). Work top scores first.

Example — qualify in chat:
You:  /leads 5
App:  Latest 5 leads:
      - #1201 Karim Uddin @ Acme Ltd — score 82 [new]
      …

4. Companies & Contacts /sccrm/companies/ · /sccrm/contacts/

  1. Companies: full CRUD + view.php (profile, linked contacts, leads, interactions).
  2. Contacts: full CRUD + view; link each contact to a company so histories stay connected.
Example: Company “Acme Ltd” → View → see Rahim (contact), 3 leads, 5 interactions in one place.

5. Tasks & Interactions /sccrm/tasks/ · /sccrm/interactions/

  1. Tasks: create with title, priority, status, due date; move new → in_progress → completed (or cancelled).
  2. Interactions: log every call/meeting/email against a lead or company — the relationship timeline.
Example — chat shortcut:
You:  /crm task Call Acme about proposal
App:  ✅ Task created …

6. Markets /sccrm/markets/

Track the 7 geographic regions (South Asia, Middle East, Europe, North America, Oceania, SE Asia, Africa): full CRUD, focus markets feed Block planning.

Example: add Market “UAE — Enterprise IT”, tag leads to it, prioritize during Block 2 (12:00–18:00 BST).

7. Knowledge Bank + Clarity /sccrm/knowledge/

Articles (CRUD + views counter)

  1. create.php → title, service, content, tags, status (draft/published).
  2. view.php?id=… → reads, related articles, FAQs. Related = same service, published, most-viewed.
  3. edit.php / delete.php → maintain; drafts hide from related lists.

Clarity prose modes (on every article)

Each article has a Clarity card — co-write/rewrite/review/lint that never invents facts:

8. FAQ /sccrm/faq/

Public FAQs per service + admin.php to manage categories/questions. Linked automatically under Knowledge articles of the same service.

Example: add “What is your proposal SLA?” → answer “Sub-2-hour technical proposals.” → appears on every proposal-service article.

9. Support chat, tickets & WhatsApp /sccrm/chat/

  1. Tickets: chat/create.php opens a ticket; view.php threads replies. Ticket AI drafts replies + triage auto-classifies (human review queue).
  2. WhatsApp: chat/whatsapp.php — scan QR to connect (Evolution API), inbox + lead outreach + CEO alerts.
Example: Ticket #42 “price query” → Ticket AI suggests reply → agent approves → sent. SLA: first response < 2h.

11. AI Library /sccrm/ai/library.php

Every agent integration on one page with live status dots (green = ready, amber = degraded, grey = missing): Content & Writing (Clarity), Browser & Trace, Memory & Knowledge, Messaging, Video & Media, Dashboards & Apps.

Example: amber dot on ToolJet → click → hint says set TOOLJET_HOST; Clarity stays green (lint is fully offline).

12. Video Productions — OpenMontage · agentic /sccrm/video/

  1. Request: title + pipeline (13: animated-explainer, cinematic, clip-factory…) + brief + budget (≤ $10 cap) → scaffolds data/video-projects/<slug>/ with brief.md + models.json.
  2. Preflight strip: runtimes (ffmpeg ✅ · remotion ✅ · hyperframes ✅/❌), capability counts, warnings; ↻ refresh preflight rescans (cached 10 min).
  3. View 👁: brief, models, file list, final-ready badge.
  4. Edit ✏️: title/pipeline/status/budget/brief (cap-enforced, audit rows updated).
  5. Delete 🗑: confirm → removes audit rows + project files.
  6. Agent flow: request → research → proposal (gate: human approves) → script → scenes → assets → edit → compose. Gates are binding — early “go ahead” never covers later gates.
Example: “Acme launch teaser” · cinematic · budget $5 →
flash Production requested: acme-launch-teaser → agent runs
pipeline_defs/cinematic.yaml → proposal gate → … → final.mp4.
Paid models need keys in external/openmontage/.env (FAL_KEY unlocks most; ELEVENLABS_API_KEY for voice). Zero-key path (ffmpeg + local TTS/STT) always works.

13. URL Trace, OSINT tools & Agent Browser /sccrm/trace/ · /trace/ · root index

  1. URL Trace (/sccrm/trace/ or /trace <url>): HTTP status, load ms, title + SEO / Security / Performance scores + improvement notes.
  2. OSINT home (root index.php): searchable directory of investigation tools by category.
  3. Agent Browser (/sccrm/trace/agent_browser.php): rendered Chromium for SPA pages — open, read, snapshot, screenshot; monitor URLs for uptime; act (click/fill) for form flows.
Example: trace client-site.com → SEO 72/100 (missing meta description), Security 90/100 → attach to the proposal as evidence.

14. ToolJet dashboards /sccrm/dashboards/tooljet.php

  1. Self-host: docker run -p 80:80 tooljet/try:ee-lts-latest → open http://127.0.0.1 → admin account → build SCCRM app (note its slug) → Profile → API tokens (copy token).
  2. Set env: TOOLJET_HOST, TOOLJET_API_TOKEN, TOOLJET_APP_SCCRM (+ CEO/TRACE slugs, workflow webhook URLs) → restart PHP.
  3. Dashboard iframes the app; workflows fire via webhook URLs (URL itself is the secret).
Example: TOOLJET_APP_SCCRM=sccrm-ops → live ops board embedded in the CRM page.

15. Security enum /sccrm/security/

Subdomain/asset enumeration helpers (amass/ASVS libraries) for client security reviews. Run scoped, with written permission only.

Example: pre-engagement: enumerate client.com subdomains → attach exposure list to the cybersecurity AMC proposal.

16. CEO Office /ceo/

  1. Dashboard (dashboard.html): revenue vs $1.5M goal, pipeline, ROAS, uptime, block tasks.
  2. 24h BST blocks: B1 06–12 South Asia · B2 12–18 ME/EU · B3 18–24 UK/NA · B4 00–06 Oceania/reboot. Tasks materialise per block; SLA timers follow the block.
  3. Chatbot (chatbot/api.php): CEO Q&A with block context.
  4. Content engine: daily SEO/social/email drafts; Playbooks (ceo/playbooks/): evergreen strategy docs (e.g. digital-marketing sales workflow).
  5. Automation: .bat schedulers + scitbd_schedule.ics keep blocks firing on Windows Task Scheduler.
Example (Block 3): US inquiry 21:40 → sub-2h proposal SLA → ≥$10k deal triggers CEO video message within 24h.

17. AutoFlows /autoflows/

  1. Hub (index.php): workflow runs, queues, retry lists.
  2. Slack (slack-php-integration/): lead alerts + CEO escalation posts into Slack channels.
  3. Public API (public/): webhook receivers (lead intake, trace callbacks).
  4. Manuals: USER_MANUAL.md + AutoFlows_User_Manual.pdf.
Example: new hot lead → AutoFlow posts “🔥 score 82 — Acme Ltd” to #sales within a minute.

18. Global search /sccrm/search.php

One box over leads, companies, contacts, tasks, tickets, articles. Enter → grouped results with deep links.

Example: search “Acme” → company card + 3 leads + proposal task + 2 tickets.
